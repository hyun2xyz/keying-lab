The edited breakdowns, alpha passes and transformed model outputs remain
subject to these underlying rights. No CC0 dedication or blanket footage
relicense is made. Unmodified downloads and extracted source sequences stay
local; obtain them from the official source pages in `dataset_manifest.json`.
The repository is a documented technical test, not a stock footage library.
Standalone source plates are not public release assets. Mixkit isolated
foreground/alpha sequences are retained locally with the run outputs; public
downloads contain the authored comparisons, review evidence and reproduction
tools. Original camera/stock files must be obtained from the listed publishers.

The three Mixkit pages were individually verified as Free License items. The
[detailed Free License](https://mixkit.co/license/modal/videoFree/) and
[Mixkit terms](https://mixkit.co/terms/) were checked on 2026-10-28. The local
downloads were made using each page's normal download control. This test does
not distribute a stock collection or standalone Mixkit cutouts.

The source portions in paired comparisons are labelled excerpts used to
explain the processing. The gray checker, native-alpha display, crop, timing,
credits and comparisons are newly authored for these tests. There is no
endorsement by any person, creator, platform, or the Blender Foundation.

The collection revision includes13 edited comparisons, reusing the earlier
five HCW tests and the existing eight-case set. No original plate or isolated
cutout/alpha is a public release asset. The bundled HCW notices are retained
locally; obtain footage from the official practice-plate page above.
